\# LanternCraft (Китайский фонарик)

Учебный проект модификации для Minecraft 1.21.1 (Fabric).



\## Совместимость

\- Minecraft: 1.21.1

\- Fabric Loader: 0.20.1+

\- JDK: 21



\## Крафт

\- 1 бамбук, 4 бумаги, 1 светопыль.
